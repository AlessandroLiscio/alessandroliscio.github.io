Como Lake Awards prize for LARA

A multilingual assistant that suggests LOINC codes for local lab test names, awarded a prize at the Como Lake Awards

The problem

Clinical labs often have their own local names for the tests they run. To describe those tests in a common way, each name has to be mapped to a code in LOINC, a standard for identifying them. Doing this by hand is slow, and it is easy to make mistakes.

What LARA does

I built LARA with CNR-IIT. The name stands for LOINC AI-based Mapping and Remapping Assistant.

The idea is simple to describe. You start from a local lab test name, and LARA suggests LOINC codes that could match it. To do that, it first searches LOINC for relevant entries and uses AI to help work out which ones fit best. It works with test names in more than one language.

LARA is an assistant, so its output is a suggestion. The people doing the mapping review what it proposes and make the decision.

The prize

LARA won a prize at the Como Lake Awards. It is a nice recognition for work on a very practical task: helping people connect the names used in their own lab to a shared standard.
